# CryptTool

A C++20-based encryption and encoding tool for Windows.

> **Status: Early Beta (v0.1.0-beta)**
>
> This project is currently under development. Some features, the GUI, and error handling may be incomplete. Not intended for production use.

## Features

Currently implemented:

- Caesar Cipher
- ROT13
- XOR
- Base64 Encoding / Decoding
- HEX Encoding / Decoding
- Copy Result to Clipboard

## Development Environment

- Language: C++20
- GUI: Windows API (Win32)
- Build System: CMake
- IDE: Visual Studio

## Planned Features

- GUI improvements
- Expanded testing and error handling
- AES-256-GCM encryption

## Notes

This project is developed for learning and experimentation.

Caesar Cipher, ROT13, and XOR are not suitable for protecting sensitive information. Base64 and HEX are encoding formats, not encryption methods.

Do not use this application to protect confidential or important data.
